title: "关于"
description: "关于 FluxBlog 与本站。"
---

FluxBlog 是一个以 [AstroPaper](https://github.com/satnaing/astro-paper) 为基础的静态技术博客，公开站点与在线写作后台位于同一仓库。

- 后端驱动：草稿、版本、图片暂存与发布由 AppPilot 提供
- Git 权威：已发布文章与图片以 GitHub 仓库为权威源
- 静态交付：构建产物部署到 `/var/www/fluxblog`，经 nginx `/blog/` 暴露

> 本站第一版为单作者，数据结构允许多个独立博客账号。
